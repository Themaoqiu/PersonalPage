## Agent Training and Evaluation

<div class="space-y-4">

  summary={"这篇工作提出 FrontierChallenge，用于评测 AI 代理是否能端到端完成真实科学工作流并交付可验证产物。基准覆盖 300 个跨学科工作流，本文先发布并评测其中 97 个任务，涉及量子化学、分子动力学、材料表征、分析化学、生命科学和电化学/环境等领域，并用 Pass Rate 与 Avg. Score 同时衡量完整交付和部分进展。作者在 12 个前沿模型和 3 种 agent scaffold 上做实验，最优配置也只完成了 20/97 个任务，通过率 20.6%。结果还显示，部分分数与真正完成度并不一致，且大量失败轨迹会在结束时声称已经完成，说明需要同时评估端到端执行和交付完整性。"}

<PaperCard
  title={"JIT-Agent: Scaling Harness Intelligence via Just-in-Time Harness Evolution"}
  arxivUrl={"https://arxiv.org/abs/2608.25593"}
  hjfyUrl={"https://hjfy.top/arxiv/2608.25593"}
  summary={"这篇工作提出 JIT-Agent，一个可训练的 harness intelligence 模型，用来为任意现成 LLM 按任务即时生成自适应的 agent harness。方法上，作者把 harness 形式化为由记忆管理、规划策略、动作协议和工具/技能编排组成的可组合工件，并训练模型在执行过程中进行定制、修复和自我演化。实验表明，借助 JIT-Agent，DeepSeek-V4-Flash 在 DeepSearchQA 和 OdysseyBench 上分别超过 GPT-5.6 9.1 分和 4.3 分，GLM-5.2 最高提升 20.2 分。控制实验还显示，JIT-Agent 生成的 harness 在多种模型族上都能稳定增益，并与成熟 agent runtime 相当。"}
