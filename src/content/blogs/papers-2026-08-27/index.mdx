<PaperCard
  title={"On-policy Distillation with Verifiable Reward"}
  arxivUrl={"https://arxiv.org/abs/2608.24696"}
  hjfyUrl={"https://hjfy.top/arxiv/2608.24696"}
  summary={"该工作提出 OPDVR，把 on-policy distillation 和可验证奖励结合起来，目标是在不增加额外超参数的前提下同时获得密集 token 级监督和任务级正确性信号。方法上，它先把 sampled-token OPD 的隐式奖励按轨迹正确性重写，再用 ReLU gating 让正确轨迹得到非负奖励、错误轨迹得到非正奖励。这样一来，采样式 OPD 被改造成可直接接入任意策略梯度算法的 RLVR 形式。在 6 个推理基准上，OPDVR 持续优于标准 OPD，并且在实验中证明了它比简单的加权组合或启发式切换更稳定、更有效。"}
/>

<PaperCard
  title={"Best Practice Critic Optimization"}
  arxivUrl={"https://arxiv.org/abs/2608.23566"}
  hjfyUrl={"https://hjfy.top/arxiv/2608.23566"}
  summary={"该工作提出 Best-Practice Critic Optimization（BPCO），目的是稳定且高效地训练 LLM 的 critic，用单次采样替代多样本 group 方法。方法上，它组合了 DPPO、有界价值预测、Monte Carlo 价值目标、未归一化策略优势和长度自适应 GAE，并允许 critic 在训练时使用参考答案或 rubric 等策略不可见的特权信息。作者通过控制实验逐项验证这些设计选择的作用，说明不稳定主要来自 critic 训练配方而不只是算法框架本身。在 1.5B 到 30B-A3B 的模型和数学推理任务上，BPCO 持续改进强 critic baseline，并在每个 prompt 只采样 1 个响应时达到或超过 group-based baseline，同时也提升了 rubric 奖励学习效果。"}
/>

## Multimodal World Model

<PaperCard
  title={"Game2World Engine: Unlocking In-the-Wild Gameplay Videos for World Model Training"}
  arxivUrl={"https://arxiv.org/abs/2608.24680"}
  hjfyUrl={"https://hjfy.top/arxiv/2608.24680"}
  summary={"该工作提出 Game2World Engine，用于把带 HUD、菜单等屏幕覆盖层的实况游戏视频转成更适合世界模型训练的干净数据。方法上，它先从真实游戏视频中抽取可复用的 UI 资产，再与干净 gameplay 片段合成时序一致的 paired 数据，并据此训练 mask-free 的 GameCleaner 来直接去除界面元素而保留场景与运动。作者同时构建了 Game2World 数据集，包含 96K 对合成视频和 1,079 个 in-the-wild 评测片段，覆盖 303 款游戏和 5,132 个已验证 UI 元素。实验显示，GameCleaner 在合成集上取得 95.36 的 AAR 和 99.00 的背景保留，在真实集上取得 80.05 的 AAR 和 99.80 的背景保留，并且用去 UI 的游戏视频训练世界模型可让 VideoReward 提升 6.83%。"}
