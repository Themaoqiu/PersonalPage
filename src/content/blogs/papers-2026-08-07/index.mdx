## 3D LLM

<div class="space-y-4">
<PaperCard
  title={"ToolArtist: Tool-Using Unified Multimodal Models for Agentic Image Generation"}
  arxivUrl={"https://arxiv.org/abs/2608.04436"}
  hjfyUrl={"https://hjfy.top/arxiv/2608.04436"}
  summary={"Text-to-image (T2I) models can produce visually compelling images, yet they remain limited on open-world tasks that require complex semantic understanding, multi-step reasoning, and the integration of external world knowledge. Existing efforts introduce agent capabilities into image generation, but they either prescribe a fixed workflow or place only a subset of the open-world image generation process under agent control. Consequently, reasoning, tool invocation, and image generation are not coordinated by a single policy. We propose ToolArtist, a fully agentic image generation model obtained by post-training a Unified Multimodal Model (UMM). ToolArtist dynamically orchestrates reasoning, external tool use, and native image generation within one unified policy. During Supervised Fine-Tuning (SFT), we equip a teacher agent with search tools alongside an image-generation tool. We then convert the collected trajectories into a UMM compatible format, where the image-generation tool is concealed while the resulting generated images are retained. During Reinforcement Learning (RL), we develop an agentic RL infrastructure for UMMs and introduce Reason-Act-Draw GRPO (RAD-GRPO), which uses complementary intent and quality rewards to jointly optimize the model. Experiments show that placing the entire open-world image-generation process under an agent policy consistently outperforms approaches with fixed pipelines or only partially agent-controlled components. We release the training data and the complete post-training infrastructure."}
/>
</div>

<PaperCard
  title={"ABSeeker: Training Long-Horizon Search Agents via Answer-Backtracked Credit Assignment"}
  arxivUrl={"https://arxiv.org/abs/2608.05102"}
  hjfyUrl={"https://hjfy.top/arxiv/2608.05102"}
  summary={"这篇工作提出 ABSeeker，目标是通过答案回溯式信用分配训练长链路搜索代理。方法先从正确答案反向恢复中间线索，再用这些线索对每一步搜索进行评分，把稀疏的轨迹级结果转成稠密的步级监督。基于此，作者构造了 ABC-SFT 和 ABC-GRPO，分别用于重加权微调和带步级奖励的强化学习。实验中，ABSeeker 仅用 8.5k 样本就在 BrowseComp 和 BrowseComp-ZH 上分别达到 37.3% 和 39.1%，加入上下文管理后进一步提升到 55.3% 和 52.9%，接近甚至达到更大规模代理的表现。"}
/>

<PaperCard
  title={"GDPevo: Evaluating Agent Self-Evolution on Real Business Tasks"}
  arxivUrl={"https://arxiv.org/abs/2608.03764"}
  hjfyUrl={"https://hjfy.top/arxiv/2608.03764"}
  summary={"这篇工作提出 GDPevo，用于评估智能体在真实企业任务上的自我进化能力。它把企业工作流拆成原子业务规则，再通过规则混合把训练任务与留出测试任务关联起来，从而让测试阶段的提升能够归因于训练经验。作者还构建了覆盖 CRM、ERP、金融、医疗、法律和数据流程的自动化数据生成管线，V1 包含 120 个任务，V2 可扩展到 240 个任务。实验在四类智能体与四种监督设置上显示，自我进化能将留出集准确率最多提升 16.44 个百分点，但最优结果仍远低于 91.6% 的 oracle 上限，说明当前智能体的自我进化能力仍未充分发挥。"}

  arxivUrl={"https://arxiv.org/abs/2608.05139"}

## Multimodal World Model
