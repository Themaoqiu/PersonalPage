## Agent Training and Evaluation

<div class="space-y-4">
<PaperCard
  title={"OpenART: Scaling Agent Red Teaming via Open-Ended Environment Evolution"}
  arxivUrl={"https://arxiv.org/abs/2608.00677"}
  hjfyUrl={"https://hjfy.top/arxiv/2608.00677"}
  summary={"这篇工作提出 OpenART，一个用于代理红队测试的开放式环境演化基准，专门评估长时序、状态会累积变化的智能体安全性。作者构建了超过 1 万个跨 50 个领域的状态化场景，并提出 Evolutionary Markov Hypergraph Attack（EMHA），通过反馈驱动的环境状态演化来提升攻击强度，而不修改模型参数。实验覆盖 75 组 agent-model 配置，EMHA 的总体攻击成功率达到 85.0%。结果还显示，随着环境复杂度上升，环境演化相比仅改写指令的优势进一步扩大，说明真实代理安全问题在长程交互中会被更充分地暴露。"}
/>

<PaperCard
  title={"AI4AI at Test-Time: Strong-to-Weak Capability Transfer via Harnesses"}
  arxivUrl={"https://arxiv.org/abs/2608.12307"}
  hjfyUrl={"https://hjfy.top/arxiv/2608.12307"}
  summary={"这篇论文研究测试时的强到弱能力迁移，提出由强模型为弱模型构造推理 harness，从而在不更新参数的情况下提升弱模型表现。作者在四个 Theory-of-Mind 基准上让 builder model 用 5% 验证集迭代优化 harness，再在完整测试集上评估。方法的核心是把不稳定的推理外包给确定性代码、任务路由和严格的答案格式约束，而不是让目标模型单纯增加推理长度。实验结果显示，目标模型平均性能几乎翻倍，从 0.49 提升到 0.91，且较弱模型收益最大。"}
/>

<PaperCard
  title={"SkillZip: Contract-Preserving Graph Compression for Scalable Agent Skill Libraries"}

/>

## Multimodal World Model

  arxivUrl={"https://arxiv.org/abs/2608.12314"}

  summary={"这篇工作提出 StateFlow，用显式且持久化的 3D 世界状态来做预可视化生成，替代传统一次性文本到图像/视频的弱可控流程。方法上，它把场景结构、演化和相机统一放进可编辑的 3D 世界状态中，并分为构建、演化和访问三个阶段：先把 2D 内容提升为一致的 3D 世界，再根据用户意图做结构化状态更新，最后通过渲染反馈细化相机轨迹。系统还结合现成的视频模型提升最终视觉质量。实验表明，该框架能生成更高质量、便于迭代编辑的 3D 世界，适合视频创作和类游戏原型制作。"}

<PaperCard

  arxivUrl={"https://arxiv.org/abs/2608.09926"}
