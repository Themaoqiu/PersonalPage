## Agent Training and Evaluation

  arxivUrl={"https://arxiv.org/abs/2608.19880"}

  summary={"这篇工作提出 EnvHarness，一个可插拔的环境包装层，用来在不修改底层环境逻辑的前提下重塑静态环境，使其能针对智能体的薄弱点动态变化。作者还提出 EnvRigger，先把目标策略当作黑箱，观察其轨迹诊断缺陷，再自动合成 EnvHarness 组件并用新 rollout 验证。实验覆盖四个领域的五个基准，结果显示它优于原始环境和领域专用环境生成管线，在留出实例上最高提升 9.0 分，同时执行步数减少 9.8%。此外，它还能为强化学习提供更好的优化信号，支持策略与环境的持续协同进化。"}
/>

<PaperCard
  title={"FACET: Preserving Source Intent and Executable State in Terminal Task Synthesis"}
  arxivUrl={"https://arxiv.org/abs/2608.18580"}
  hjfyUrl={"https://hjfy.top/arxiv/2608.18580"}
  summary={"这篇工作提出 FACET，用于合成可执行的终端任务，并同时解决源意图保留与跨工件一致性问题。方法上，它先把相关 agent 技能重构为信息密集的场景，再构建并修复执行环境，最后在共享的容器状态上生成指令、参考解答和验证器，并通过执行式校验与定向修复减少工件不一致。作者强调这种“环境落地”的共享状态能让任务、解答和验证器更对齐。实验表明，FACET 生成的复杂终端任务能提供密集的可执行监督，利用这些成功轨迹进行微调后，在 Terminal-Bench 2.1 上能稳定提升不同规模模型的表现。"}
/>

<PaperCard
  title={"MemTrapBench: Benchmarking Cognitive Traps in LLM Memory Use"}
  arxivUrl={"https://arxiv.org/abs/2608.20202"}
  hjfyUrl={"https://hjfy.top/arxiv/2608.20202"}
  summary={"这篇工作提出 MemTrapBench，用来评测 LLM 在使用记忆时是否会陷入认知陷阱，而不只是考察记忆能否被正确检索。作者把失败模式归纳为两类：Reasoning Fixation 和 Belief Distortion，并据此系统测试了两类模型与五种代表性记忆框架。实验显示该基准很难，所有评测的记忆策略都不如不使用记忆的设定，最强方法也会带来超过 10% 的性能下降。为缓解这一问题，论文提出 AdaptiveMem 作为推理时方法，在标准记忆基准上保持或提升性能的同时减轻认知陷阱。"}
/>

  arxivUrl={"https://arxiv.org/abs/2608.13120"}
